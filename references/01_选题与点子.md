# 01 · 选题与点子（IP）

24 条。这一域最硬，因为**点子的病在写剧之前就已经注定**，改稿救不回来。

规则正本：`data/rules.tsv`（`python3 scripts/xr.py domain IP`）。

## 一、九条负面病（IP-01 ~ IP-09）

这九条来自一次真实复盘：一天之内，同一个智能体在自己写的点子里犯了两次，
而**法条、清单、检测器当时全都已经存在**——只是"查表"这个动作没有发生。
所以这九条的用法是**写之前过一遍、写之后再过一遍**，不是看完点头。

| 编号 | 病 | 一句话判据 |
|---|---|---|
| IP-01 | 修复类职业当主线 | 核心动作是"把坏掉的东西弄好" |
| IP-02 | 承重焊接 | "A 使 B 成为可能"需要另写一段话解释 |
| IP-03 | 细致病 | 胜负落在要凑近才看得见的东西上 |
| IP-04 | 量级悬在中间 | 杠杆与绝境两条轴都没到顶 |
| IP-05 | 万能钥匙 | 一个技能解决三类以上问题 |
| IP-06 | 科研病 | 判断被写成读数，精度超出需要 |
| IP-07 | 公式核梗 | 换掉人名这句话照样成立 |
| IP-08 | 怪癖病 | 无成因、不参与因果、只当卖点 |
| IP-09 | 账本病 | 价值转移全靠物件易手 |

**最常被低估的是 IP-04。** 它不是"故事不够刺激"，而是"这个设定不产生后果"：
主角的选择不影响别人，他也不会失去一切。便宜的解不是加大冲突，是**身份落差装置**
——让主角在观众眼里是小人物，在世界里是大人物（"马甲"在站内 30,571 部里是第三大设定）。

**IP-07 有两个变种，第二个更难自查。** 时钟型（"每到 X 就 Y"）一眼能看出；
对仗递进型（"他每 A 一分，她就 B 一分"）读起来工整、有张力，**越顺口越可疑**。
判据只有一个：把人名换掉，这句话还成立吗？成立就是公式，不是故事。

## 二、六条正面自检（IP-11 ~ IP-16）

正面清单的作用不是加分，是**判断这个点子有没有"白送"东西**。

- **P1 自带量级**（IP-11）：私人目标需不需要额外解释才接上公共后果？需要，就还没焊上。
- **P2 自带场面**（IP-12）：读完能立刻说出三个想看的场面吗？说不出，设定没白送。
- **P3 自带对手**（IP-13）：对手是世界的必然产物，还是你为了有冲突而加的？
- **P4 双引擎相乘**（IP-14）：情欲 × 幽默是烂点子的唯一解药。注意这两者**相乘不相加**。
- **P5 干净的赢**（IP-15）：挫败放在赢之前是蓄力，放在赢之后是扣税。
- **P6 古老原型**（IP-16）：匠人打新刀是创造，磨刀匠磨旧刀是修复——同一条街，两个命运。

## 三、四问自检（IP-17、IP-18）

**必须写出来，不能默想。** 因为默想过没过，事后无从判断；写出来，漏没漏一眼可见。

```text
点子：〈一句话〉
① 病灶自查：N1 无（理由）／N3 无（理由）／N4 去哪条轴／N7 无（理由）
② 量级：杠杆——〈一句话说明为什么不需要额外解释〉
③ 三个场面：〈场面一〉／〈场面二〉／〈场面三〉
④ 胜负物可见性：〈那个东西〉，三米外看得见（合格/不合格）
```

模板见 `templates/点子四问模板.md`。

`IP-18` 补了一刀：凡是亲手写点子、种子、启动脚本，提交前**必须真跑一次检测器**。
写下来的规范不会自己执行，只有被跑起来的检查才是防线。

## 四、选剧与选题适配（IP-19 ~ IP-23）

这一组管"拿到的这个 IP／这部剧要不要做"，不是"这个点子好不好"。

**入库六问（IP-19）**，六问有一问答不上，就不进选题管线：

1. 商业位置：收入锚点、下载增长、低成本供给，还是品牌影响力？
2. 本地语法：不是把中国／欧美梗换地名，而是当地观众已熟悉的冲突结构。
3. 第一集钩子：60 秒内能不能出现羞辱、危险、秘密、身体反应或不可逆损失？
4. 第三集付费墙：第三集前是否已形成"必须知道下一步"的未兑现承诺？
5. 制作可行性：当地演员、场景、语言、服装、音乐、合规是否在预算内可实现？
6. 差异化证据：和同类库、头部热门比，是否至少有一个新机制？

**本地语法不是换地名（`IP-20`）**：拉美不等于足球＋贫民窟，东南亚不等于泰国灵异，
中东不等于谢赫＋奢华，欧美不等于狼人＋总裁。这些都可以是有效赛道，但不能代表整个地区。
**判据是：它不是把中国／欧美梗换个地名，而是当地观众已熟悉的冲突结构。**

**定格成立（IP-21 ~ IP-23）** 是从"静图＋旁白"这种交付形态倒推出来的判据，
但它对普通短剧也有效：如果一部戏的关键时刻**必须看见人动到一半**才能明白他在干什么，
说明它的戏剧张力不依赖构图、人物、物件、空间关系——这类戏改编成任何"帧优先"的形态都会失败。

三条配套：服化道能不能配一个表情把信息交代完（IP-22）；
冲突落在"说／看"还是"打／跑"（IP-23，本质是旁白密度）；单集能不能拆成 3–5 个一图一意（`STR-10`）。

## 五、IP-24：事实提取与解释分离

这一条不是判据，是**所有评估的前置条件**。

把这几件事分开记录，永不合并：

1. 原文明确写了什么（附章节锚点）
2. 人物自己怎么理解
3. 研究者／评估者推断了什么
4. 原文没有交代什么（写"未知"，不替它补）

理由是硬账：**把人物一时的策略伪装成故事硬规则，是这类评估最常见的失效方式。**
一份"主角必须永远低调"的结论，可能只来自"此人此处选择退让"这一处观察。

## 六、这一域的适用边界

- 九条负面病来自**男频轻爽／爽剧**口径。做文艺片、悬疑、现实题材时
  `IP-01`／`IP-10` 仍然成立（它们是商业口径不是美学判断），但 `IP-15`（干净的赢）
  需要按项目重估。
- `IP-19 ~ IP-23` 的商业参数与平台有关，会过期。核验日期见 `09_来源与出处.md`。
- `IP-16` 的"古老原型"清单是经验集，不是封闭集。
