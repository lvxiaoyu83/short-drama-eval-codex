# 02 · 爽点与兑现（HOOK）

15 条。这一域回答一个具体问题：**为什么这段读着不爽？**

规则正本：`data/rules.tsv`（`python3 scripts/xr.py domain HOOK`）。

## 一、核心诊断：情绪过程缺环节

`HOOK-01` 是这一域的地基。一件事只交代了"经过"，没有写出"情绪过程"：

> "主人公赴宴、给人喝汤、证明本事、获得感谢" —— 只交代了事情经过。

完整的戏要让观众经历：有人嫌他不配来 → 有人看不上那口锅 → 有人拿昂贵补品作比较 →
有人愿意替他争取试用 → 效果出现后受益者亲口说变化 → 原先看不起的人收回原话 →
众人开始求下一碗 → 主人公得到更好待遇 → 从容享受。

**设计时就为这些留位置**，不能先把动作情节塞满，再看剩下几句能不能放一点反应。

## 二、进展的定义（HOOK-02）

人物仍在同一个房间，主角仍没有动手，也可以已经走过好几轮：

从不准进门 → 勉强允许 → 全场附和 → 有人愿试 → 怀疑有效 → 承认自己不如 → 出钱购买 → 请求赏脸。

每轮至少让一项东西发生**可听见、可看见**的变化：期待、比较标准、信心、支持阵营、
出手资格、出价条件、人物认识、尊重程度、亲密程度、谁在求谁。

**不要求每轮都增加新外部任务、危险或世界观信息。** 这是最常被写反的一条：
以为"不爽"是缺事件，实际是缺关系位移。

## 三、事件九环节（HOOK-08）

```text
想要一个结果
→ 建立比较标准与待遇落差
→ 多轮拉扯和烘托
→ 获得展示机会
→ 漂亮展示
→ 确认结果与分量
→ 原话回收、态度翻转
→ 实际待遇和利益兑现
→ 享受余味，生出新的愿望
```

**这是功能顺序，允许交织合并，不是固定九场、九轮或九集。**
小事件可以在数次对话里走完，大事件可以跨集展开。

写事件卡时，展示前和展示后都要有**具体人物、原话或动作**。
只填"铺垫足""众人反转""继续爽"不算完成（`HOOK-14`）。

## 四、收尾七层（HOOK-10）

| 层次 | 适合的反应 | 比上一层多交付什么 |
|---|---|---|
| 本人确认 | "刚才端杯子都抖，现在一点不抖了。" | 效果真实进入人的感受 |
| 旁证确认 | "你昨天起身还要两人扶，今天自己走过来了！" | 用旧状况对照新结果 |
| 分量确认 | "我送来那东西养了半年，也没让您走成这样。" | 把厉害放到此前标准上称量 |
| 原话打脸 | "我刚才还嫌这是口破锅，是我不识货。" | 前面那笔轻视由本人认账 |
| 主动求取 | "刚才那碗我不该推开。能不能也给我留一份？" | 同一人物从拒绝变成渴望 |
| 实际兑现 | 搬椅子、付款、撤条件、亲自服务、公开偏爱 | 认可变成可以享用的待遇 |
| 余味 | 接受照顾、开句玩笑、决定谁先来 | 停留在改变后的生活与关系里 |

**不要求每次七项全写。本轮承诺了什么，就把相应层次写足。**
核心打脸事件不能省本人认账；核心受宠事件不能省主动亲近；核心赚钱事件不能一直不兑现收益。

## 四点五、展示与台词的分工（HOOK-05、HOOK-06、HOOK-12、HOOK-13）

- **展示要漂亮，允许长，必须看足**（`HOOK-05`）：动作开始后认真完成结果；能增加美感、
  能力分量、生活变化或人物尊严的步骤应保留。不机械要求"一秒见效"，也不在关键动作
  即将发生时反复打断来拖延。这两句是一对：**不许快进，也不许插播。**
- **关键意思直接说清并由事实托住**（`HOOK-06`）：贵在哪、强在哪、好在哪不靠观众猜。
  直白不等于人人同一口吻：蛮横者嘴硬、老板直报价值、受益者说生活感受。
- **展示可分层，每层兑现不同内容**（`HOOK-12`）：喝下→手稳（已起效）；自己站起（能行动）；
  走回主位亲自决定（生活与尊严归本人）。三个步骤价值不同，所以可以从容展开。
- **羡慕、嫉妒、渴求把下一件事带出来**（`HOOK-13`）："我也想要一份"引出求助；
  "这么好的东西必须归我"引出争夺。**先让本轮兑现站稳**，再引出下一轮。

## 五、四个常见误写

1. **展示后不写反应**（`HOOK-03`）。"众人震惊"是提纲，不是成品。
2. **拿"凑拉扯"当拉扯**（`HOOK-04`）。已被事实解决的问题必须往下一层走：
   从"没有用"→"究竟有多好"→"我能不能也得到"。对已确认能力反复自我怀疑、
   同一许可问题推翻重来、临时发明复杂限制，都不是拉扯。
3. **展示前不选证明物**（`HOOK-11`）。不要等结果出来后才临时发明一个人人没听过的
   鉴定标准来宣布厉害。证明物要前后都在，观众才比得出来。
4. **主要低估者悬空**（`HOOK-09`）。不能借"反派还要留着"让所有前账悬空。

## 六、洁癖对抗：删轮检验（HOOK-15）

删掉这一轮，如果观众仍完全一样地期待、理解和感受下一步 → 合并。
如果删掉后少了"连这个人都这样说""他终于亲口承认了"的味道 → 保留。

这一条是对 `HOOK-01` 的反向约束：**要求写足情绪过程，不等于允许灌水。**
两者同时成立的条件是：每一轮都改变一项**可命名的**东西。

## 七、这一域的适用边界

- 本域全部来自轻爽口径。写虐恋、悬疑、文艺向时，`HOOK-07`（允许享受）与
  `HOOK-10`（收尾七层）需要重估，但 `HOOK-02`（关系位移＝进展）是通用诊断工具。
- "不允许惨胜"（`IP-15`）是项目选择，不是普适美学。写悲剧时不要套。
