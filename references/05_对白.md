# 05 · 对白（DIA）

16 条。这一域是全库最细的一块，因为"读起来平"是最难用抽象语言治疗的病。

规则正本：`data/rules.tsv`（`python3 scripts/xr.py domain DIA`）。

## 一、总口径（DIA-01）

> 让人物当着眼前这个人的面，把自己想要的、介意的、喜欢的、不服的说出来。

先读这场已经发生了什么，再进入人物：**现在谁最让他不舒服，什么最让他动心，
他怎样说才能让眼前的人改口、答应、靠近，或者别再欺负他。**

句子长短跟着这一口气走。"姐姐，你也没告诉我是给死人治病啊，我又不是孙悟空，
还能给人改生死簿呀？"可以一口气说；别人答应一个具体请求时，只回"好"也可以。

## 二、五个正面特征

| 编号 | 特征 | 对照 |
|---|---|---|
| DIA-02 | 直白：说到人和事上 | "我不接受这个方案"只给结论；"你爸欠的钱，凭什么让我妹妹去还？"还能听见他护谁、恨什么 |
| DIA-03 | 犀利：戳中对方此刻的企图或心虚 | "我开价两万，你还个二百，有你这么砍价的吗？" |
| DIA-04 | 畅快：情绪上来了就往前走 | 不要刚露出情绪又用一句礼貌通知把它压平 |
| DIA-05 | 流畅：一层意思顺着气口走 | "你也没告诉我是给死人治病啊"同时说出"你瞒了我""要求太离谱""我被你坑了" |
| DIA-16 | 视觉变化配台词 | 剧情的重要视觉变化一般配合在场角色的台词，让人既看到也听到 |

**犀利必须有一个明确对象。** 骂得多、典故多、逻辑反转多，都不能替代这一点。

## 三、四条禁令（这一域最容易被违反）

1. **禁止碎句拼接**（`DIA-06`）：不写"钱拿走，灶留下""免费。一张""给。先看""好。不打扰"。
   连续碎句会把一个有愿望的人写成办事流程。
2. **禁止整齐对照与作者式金句**（`DIA-07`）：不靠"不是 A 而是 B""A 不管用，B 才管用"
   制造聪明感；不用低烈度比较给普通场面垫字。
3. **禁止用概括词替人物完成回应**（`DIA-09`）："金钱无法衡量情感的价值"把人推到场面外，
   像已经发表完观点。不用"尊重、信任、选择、边界、价值"这一类词。
4. **禁止用括号里的情绪替代**（`DIA-12`）："暴怒、心疼、惊艳"不能给一句万能通知
   读出复杂感情；语气与动作只在影响表达、回应或局面时写。

注意 `DIA-07` 的下半句：**句子短、好记或有对照并不自动有错**——要看它是否来自
眼前的冒犯、能力展示或感情关系。禁令杀的是"可替换的漂亮"，不是所有漂亮。

## 四、两条可执行的自检

**可替换检验（DIA-14）**：一句漂亮话若能手换成店、房、公司、梦想而几乎不变，通常值得重写。

**听者自检（DIA-10）**：说完后，听者为什么会接这一句？如果人人都回答得准确、合理、礼貌，
而没人嘴硬、着急、羡慕、想多得一点，回到人物自己的兴趣重写。

## 五、审读三分法（DIA-15）

改稿时先分清是哪一种"不够"：

| 症状 | 处理 |
|---|---|
| 信息不够 | 补本场必要事实（`DIA-08`） |
| 愿望不够 | 回故事找"这场为什么值得发生"，不要在语言上治 |
| 愿望已足而语言太淡 | 重写措辞与反应 |

**第三种情况继续加设定是错的；第一种情况只让演员喊得更响也是错的。**

## 六、重复与格式

- **重复要跟着变化**（`DIA-11`）：再喊"别走"可能是人已迈步；再要"给我看看"可能是对方还在藏。
- **纯台词稿只写必要项**（`DIA-13`）：角色名、对白、必要短动作；不塞镜号、秒数、回合编号或创作分析。
- **只用当时知道的事实**（`DIA-08`）：事实靠本场和必要前情；夫妻不用相互介绍婚龄。

## 七、这一域的适用边界

- 这一域绑定了**特定项目的口吻偏好**（拒绝碎句、拒绝整齐对照、拒绝作者式金句）。
  如果你的项目偏好短句美学或文言腔，`DIA-05 ~ DIA-07` 需要重写而不是照搬。
- `DIA-14`（可替换检验）与口吻无关，通用。
- 真实对白的证据来自 50 段行业连续台词（见 `09_来源与出处.md`），本仓库不含原文。
